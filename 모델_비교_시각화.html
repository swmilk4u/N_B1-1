1. 시작 준비

학습 목표

GitHub 계정을 만들고, Git과 편집기를 설치해 작업 준비를 마친다. 이름/이메일을 Git에 등록해 기록이 내 이름으로 남도록 한다.

  • GitHub 계정 만들기, VS Code 설치
  • git config --global user.name "이름" 내 이름 등록
  • git config --global user.email "이메일" 내 이메일 등록

2. GitHub 핵심 개념 (쉽게 이해하기)

학습 목표

Git은 "변경 기록 도구", GitHub는 "인터넷 보관함+협업 공간"이라는 큰 그림을 이해한다.

  • 프로젝트 폴더: 파일과 변경 기록이 담긴 프로젝트의 집
  • 작업 갈래: 메인과 분리된 안전한 실험 구역
  • 변경 내용 저장: 바뀐 내용을 한 묶음으로 기록
  • 올리기/가져오기: 내 컴퓨터 ↔ GitHub 사이 동기화
  • 코드 검토 요청: 작업 갈래 변경을 메인에 넣기 전 리뷰·토론 절차

3. 첫 프로젝트 폴더 만들기

학습 목표

웹에서 바로 프로젝트 폴더를 만들고 기본 파일을 준비한다.

1
GitHub 로그인 → New → Repository 클릭
2
이름 (예: hello-github), 공개/비공개 선택
3
README 만들기 체크 권장, .gitignore 선택 가능
4
Create repository 클릭 → 완료!

4. 변경 내용 저장과 올리기

학습 목표

수정 → 올릴 내용 고르기 → 변경 내용 저장 → 올리기 기본 흐름을 익힌다.

1
git status — 무엇이 바뀌었는지 보기
2
git add . — 바뀐 것 모두 고르기
3
git commit -m "인사 메시지 추가" — 변경 내용 저장
4
git push — GitHub에 올리기

5. 작업 갈래로 안전하게 실험하기

학습 목표

새 작업 갈래를 만들고 이동·공유·정리하는 방법을 익힌다.

  • git checkout -b feature/hi — 새 작업 갈래 만들고 이동
  • 작업 후: git push -u origin feature/hi
  • 메인으로: git checkout main
  • 겹침 문제 해결: git pull → 충돌 파일 수정 → git add → git commit

6. 코드 검토 요청으로 합치기

학습 목표

"코드 검토 요청"을 만들고, 설명 쓰기·의견 반영·합치기까지 마무리한다.

1
작업 갈래를 올리면 "Compare & pull request" 버튼 클릭
2
제목/설명에 "무엇을, 왜 바꿨는지" 적기
3
Create pull request → 리뷰 의견 반영 후 Merge

7. 협업 사례 (둘이 함께 작업하는 시나리오)

학습 목표

두 사람이 안전하게 나눠 작업하고 코드 검토 요청으로 합치는 전 과정을 익힌다.

A
GitHub에 프로젝트 폴더 만들고 B를 협업자로 초대
B
git checkout -b feature/welcome 작업 갈래 만들기 → 수정 → 저장 → 올리기
B
코드 검토 요청 생성 (변경 내용·이유·테스트 방법 기재)
A
코드 검토 후 댓글로 제안, 승인 시 Merge
A+B
git checkout main; git pull 로 최신 상태 맞추기

✅ 체크리스트

  • 이름/이메일 설정 완료

  • 변경 내용 저장·올리기 1회 이상 완료
  • 작업 갈래로 작업 후 코드 검토 요청 생성·합치기
  • 메인 최신으로 가져오기 (git pull)

2️⃣ GitHub가 뭔가요?

학습 목표

✔ GitHub가 어떤 서비스인지 설명할 수 있어요 · ✔ 딱 5개 표현을 이해할 수 있어요

GitHub = 내 작업물을 인터넷에 저장하고 다른 사람과 함께 작업할 수 있는 공간

일상 속 예시GitHub에서는
📂 구글 드라이브파일을 인터넷에 저장
💬 카카오톡 단톡방팀원과 함께 작업
🎮 게임 세이브 포인트작업 내용을 단계별로 저장
📄 문서 복사본 만들기원본 건드리지 않고 수정

💛 지금 다 외우지 않아도 괜찮아요! 뒤에서 하나씩 자세히 설명해 드릴게요 😊

3️⃣ 내 첫 번째 폴더 만들기

학습 목표

✔ GitHub 계정을 직접 만들 수 있어요 · ✔ 나만의 첫 번째 프로젝트 폴더를 만들 수 있어요

1
오른쪽 위 "+" 버튼 → "New repository" 선택
2
폴더 이름 입력 (예: my-first-project), 설명 한 줄 작성
3
소개 파일 → ✅ 체크하기 (README 추가) ⭐
4
"Create repository" 클릭 → 완성! 🎉

4️⃣ 저장하고 올리기

학습 목표

✔ 작업 내용을 저장하는 3단계 흐름을 설명할 수 있어요 · ✔ GitHub에 직접 올릴 수 있어요

1
git add . — 올릴 파일 고르기 (바뀐 파일 전부 선택)
2
git commit -m "처음으로 파일을 올렸어요" — 변경 내용 저장하기
3
git push origin main — GitHub에 올리기 🎉

💡 꿀팁: 저장 메모는 "무엇을 왜 바꿨는지" 담으면 완벽해요! 미래의 내가, 그리고 팀원이 정말 고마워할 거예요 😄

학습 목표

💛 실수해도 괜찮아요! 복사본에서 작업하니까 원본은 항상 안전하게 보호된답니다 😊

  • git checkout -b 새작업공간이름 — 새 작업 공간 만들고 이동

학습 목표

💡 "내가 작업한 내용을 팀원에게 보여주고 '이거 괜찮아 보여? 문제 없으면 합쳐줘!'라고 확인을 부탁하는 과정이에요."

1

2

7️⃣ 함께 일하는 방법 (협업 사례)

학습 목표

✔ 팀 프로젝트에서 GitHub를 어떻게 활용하는지 구체적인 시나리오를 통해 이해한다.

A
프로젝트 폴더 만들고 B 초대 (Settings → Collaborators)
B
feature/signup 작업 공간 만들어 회원가입 기능 개발
B
"회원가입 기능 추가했어요! 코드 한번 봐주세요." 코드 검토 요청
A
"와, 깔끔하게 잘 만들었네요!" 댓글 후 승인 → Merge
A
로그인 기능 완료 후 동일하게 코드 검토 요청 → B가 Merge

결론: GitHub를 쓰면 여러 사람이 동시에 작업해도 코드가 꼬이지 않고, 서로의 작업을 투명하게 확인하며 더 좋은 결과물을 만들 수 있어요! 🤝

3. 내 첫 온라인 비밀 상자 만들기

학습 목표

마우스 클릭 몇 번으로 나만의 첫 온라인 코드 공간을 만들 수 있어요.

📌 핵심 따라하기: hello-world라는 이름으로 내 첫 온라인 비밀 상자를 만들어 봐요!

GitHub 로그인 후, 오른쪽 위 + 버튼 → New repository 클릭
2
이름(hello-world) 입력

4
초록색 Create repository 버튼 클릭 → 짜잔! 🎉

4. 코드 택배 보내기

학습 목표

내 컴퓨터에서 작업한 내용을 3단계에 걸쳐 안전하게 온라인으로 보낼 수 있어요.

1
물건 담기 (git add .) — "나 이 파일 바꿨어!" 알리기
2
송장 붙이기 (git commit -m "메모") — 왜 바꿨는지 메모 남기기
3
택배 발송! (git push) — 온라인 비밀 상자로 슝~ 🚀

5. 마법 복제 종이 사용법

학습 목표

원본 코드를 절대 망가뜨리지 않는 안전한 작업 습관을 익힐 수 있어요.

📌 핵심 따라하기: my-idea라는 이름으로 나만의 마법 복제 종이를 만들어 봐요.

  • git checkout -b my-idea — 새 복사본 만들고 이동
  • 마음껏 수정·실험 → 원본(main)은 항상 안전! ✅

6. "제가 한 작업, 한번 봐주실래요!" (코드 검토 요청)

학습 목표

복사본에서 작업한 내용을 원본에 합치기 위해 '코드 검토 요청'을 보낼 수 있어요.

1
복사본에서 작업 후 git push
2
GitHub에서 초록 "Compare & pull request" 버튼 클릭
3
무엇을 왜 바꿨는지 제목·설명 작성
4
Create pull request → 팀원 확인 후 Merge pull request ✅

7. 진짜처럼! 철수와 영희의 팀 프로젝트

학습 목표

철수
프로젝트 온라인 폴더 만들고 영희 초대 · feature/login 복사본 생성
