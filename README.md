# LLM 모델 비교·선정 및 프롬프트 시스템 설계 프로젝트

## 프로젝트 개요
이 프로젝트는 3가지 대형 언어 모델(LLM)을 동일한 업무 과업에 적용하여 성능을 비교하고, 최적의 모델을 선정하며, 프롬프트 시스템을 설계·검증하는 실전 학습입니다.

## 비교 대상 모델
- **모델 A**: GPT-5 (x1 토큰량)
- **모델 B**: Claude Sonnet 4.6 (x1 토큰량)
- **모델 C**: Gemini 2.5 Pro (x1 토큰량)

선정 이유: 동일한 x1 토큰량 기준으로 비교하며, 각기 다른 회사의 대표 모델로 기술적 다양성 확보

## 업무 과업
**보고서 개요 생성**: GitHub 입문자를 위한 첫 리포지토리 작성 가이드

### 타겟 사용자
GitHub를 처음 접하는 개발자 및 비개발자

### 주된 목표
기초 필수 용어 및 사용법 숙지 가이드 작성

## 제출 산출물 구조

### 1. 모델 비교·선정 보고서
- 파일: `01_LLM모델_비교_및_선정_보고서.md`
- 내용: 평가 축별 점수, 모델별 강점/약점, 최종 선정 근거

### 2. 프롬프트 시스템 설계 문서
- 파일: `02_프롬프트_시스템_설계_문서.md`
- 내용: 문제 정의, 페르소나, 시스템 프롬프트, Few-shot 예시, 환각 검증, 개선 이력

### 3. 실행 로그 (대화 로그)
- 파일: `03_실행_로그.md`, `03_실행_로그.txt`
- 내용: 10턴 이상 대화 전문, 샘플 보고서, 문제 지점 및 개선 요약

## 대화 로그 입력 템플릿

각 모델별로 동일한 입력 및 상호작용을 기록하는 파일:
- `모델 A_GPT-5_대화_로그.txt`
- `모델 B_Claude_Sonnet4.6_대화_로그.txt`
- `모델 C_Gemini_2.5_Pro_대화_로그.txt`

모든 파일은 10턴 이상의 대화 입출력을 기록할 수 있도록 준비되어 있습니다.

## 사용 환경
- 사용 채널: 웹 (네이토)
- 사용 날짜: 2026.6.4.(목)
- 요금제: 유료(또는 평가판)

## 평가 축 (1~5점)
1. **정확성**: 사실·수치·문맥 대응 정확도
2. **한국어 자연스러움**: 한국어 표현의 유창성/자연스러움
3. **형식 준수**: 템플릿/출력 규칙 준수
4. **문맥 유지**: 10턴 대화 시 문맥 유지 능력
5. **응답 속도**: 결과 출력 속도 및 안정성
6. **비용 효율**: 토큰 비용 또는 요금 대비 성능
