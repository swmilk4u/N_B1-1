2️⃣ GitHub란 무엇인가?
목적: 핵심 개념을 쉬운 언어로 설명

2-1. Git vs GitHub 차이점
구분	Git	GitHub
정의	버전 관리 도구	Git 저장소 호스팅 서비스
위치	내 컴퓨터(로컬)	인터넷(원격)
비유	작업 일지	작업 일지 보관 클라우드
2-2. 알아야 할 핵심 용어
📁 Repository(리포지토리): 프로젝트 폴더
📸 Commit(커밋): 변경사항 저장 스냅샷
⬆️ Push(푸시): 로컬 → 원격 업로드
🌿 Branch(브랜치): 독립적인 작업 공간
🔀 Pull Request(PR): 변경사항 합치기 요청

git checkout main

# 브랜치 삭제
git branch -d feature/새기능

git checkout main

# 작업 공간 목록 보기
git branch
