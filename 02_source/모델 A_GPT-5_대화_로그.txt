GitHub 핵심 개념(쉽게 이해하기)
배우는 것(학습 목표)
Git은 “변경 기록 도구”, GitHub는 “인터넷 보관함+협업 공간”이라는 큰 그림을 이해한다
프로젝트 폴더, 작업 갈래, 변경 내용 저장, 올리기/가져오기, 코드 검토 요청의 역할을 구분한다
핵심 설명
Git: 파일이 어떻게 바뀌었는지 사진 찍듯 기록
GitHub: 그 기록을 인터넷에 올려 함께 일하는 곳
프로젝트 폴더: 파일과 변경 기록이 담긴 프로젝트의 집
작업 갈래: 메인과 분리된 안전한 실험 구역
변경 내용 저장: 바뀐 내용을 한 묶음으로 기록
올리기/가져오기: 내 컴퓨터와 GitHub 사이에 올리고 받아오기
코드 검토 요청: 내 작업 갈래 변경을 메인에 넣기 전 리뷰·토론 절차

자주 만나는 문제(빠른 해결)

올리기 실패(권한/토큰): GitHub 로그인, 개인 액세스 토큰(PAT) 또는 SSH 키 설정
주소가 틀림: git remote -v 로 주소 확인
최신이 아니라 거절됨: git pull --rebase 로 먼저 받아오기
이메일 달라서 기여가 안 보임: git config --global user.email 재설정
메인으로 직접 올리기 차단됨: 브랜치 보호 규칙일 수 있으니 코드 검토 요청으로 합치기
