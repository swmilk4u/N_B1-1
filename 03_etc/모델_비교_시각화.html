과제 목표 답변 (5항목)
1
LLM의 확률적 생성과 환각(Hallucination)
LLM은 다음에 올 단어를 확률적으로 예측하여 문장을 생성합니다. 학습 데이터의 패턴을 바탕으로 그럴듯한 내용을 구성하기 때문에, 검증 근거가 부족하거나 질문이 모호할 때 사실과 다른 내용(환각)이 발생할 수 있습니다.
📌 실제 테스트: 날짜/시간 질문에서 Gemini만 정확히 답변, GPT-5와 Claude는 "답변 불가" 처리 → 환각 없이 안전 대응
2
Zero-shot / Few-shot / Reasoning Prompt 차이
Zero-shot: 예시 없이 지시만 → 빠르지만 결과 편차가 큼
Few-shot: "좋은 입력→좋은 출력" 예시 함께 제공 → 출력 형식과 톤 안정화
Reasoning Prompt: 단계적으로 풀도록 유도 → 복잡한 과업의 정확도 향상, 필수 항목 누락 방지
3
평가 축과 근거 기반 모델 선택
동일한 입력 조건을 모든 모델에 적용한 뒤, 6개 평가 축(정확성, 한국어 자연스러움, 형식 준수, 문맥 유지, 응답 속도, 비용 효율)별 점수와 근거 문장을 기록하면 "느낌"이 아닌 재현 가능한 비교가 가능합니다.
4
페르소나·시스템 프롬프트의 영향
일관성: 페르소나를 지정하면 응답 톤과 관점이 안정 → 턴 간 일관성 향상
안전성: "모르면 모른다", "근거 제시" 규칙 명시 → 환각 위험 감소
형식 준수: 출력 스키마(제목→목차→설명→학습 목표) 고정 → 재생성 시 동일 형식 유지
5
생성 결과 검증 및 반복 개선
환각 검증 질문 5개를 준비하고 기대 정답 + Pass/Fail 기준을 세운 뒤, 오류 발생 시 프롬프트를 수정(v1→v2)해 재실행합니다. 전후 결과를 기록하면 개선 과정을 동일하게 재현할 수 있습니다.
🔄 v1(간단) → v2(단계적 유도): 필수 항목 충족률, 형식 일관성, 용어 일관성 모두 개선
