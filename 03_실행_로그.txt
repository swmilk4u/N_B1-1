

## 샘플 보고서

### GitHub 입문자를 위한 첫 리포지토리 작성 가이드

**1. 머리말**
GitHub는 코드를 저장하고 관리하는 온라인 공간입니다.

**2. GitHub란 무엇인가**
프로젝트를 관리하는 플랫폼으로, 리포지토리(저장소)를 통해 파일을 저장합니다.

**3. 리포지토리 생성**
새로운 리포지토리를 만드는 방법과 공개/비공개 설정을 안내합니다.

**4. 커밋과 푸시**
커밋: 변경 내용 저장, 푸시: 로컬 내용을 GitHub에 올리기

**5. 브랜치 기본**
브랜치는 작업을 나누는 도구로, 안전하게 새로운 기능을 시도할 수 있습니다.

**6. PR(코드 검토 요청) 기본**
PR을 통해 변경 내용을 공유하고 검토를 받습니다.

**7. 협업 사례**
팀 작업 시 변경 내용 공유 및 병합 흐름을 설명합니다.

**8. 학습 목표**
GitHub 기본 이해, 첫 리포지토리 생성, 변경 관리, 협업 능력 습득


### 대화로그(질문 리스트)
1. GitHub를 처음 사용하는 사용자에게 적합한 보고서 개요를 만들어줘. 주제는 "GitHub 입문자를 위한 첫 리포지토리 작성 가이드"이고, 톤은 친절하게 해줘. 필수로 GitHub 개념, 리포지토리 생성, 커밋/푸시, 브랜치, PR 기본을 포함해줘.
2. 가능한 쉬운 말로 설명해줘.
3. 각 항목마다 학습 목표도 넣어줘. 그리고 전문 용어 대신 쉬운 표현을 써줘. 예를 들면 "커밋"은 "변경 내용 저장"처럼.
4. 목차에 "협업 사례"도 추가해줘. 그리고 "PR" 설명은 "코드 검토 요청"으로 쉽게 설명해줘.
5. 톤은 더 친절하게, 그리고 확인 질문 없이 바로 결과를 보여줘.
