### 대화로그(질문 리스트) 1. GitHub를 처음 사용하는 사용자에게 적합한 보고서 개요를 만들어줘. 주제는 "GitHub 입문자를 위한 첫 리포지토리 작성 가이드"이고, 톤은 친절하게 해줘. 필수로 GitHub 개념, 리포지토리 생성, 커밋/푸시, 브랜치, PR 기본을 포함해줘. 2. 가능한 쉬운 말로 설명해줘. 3. 각 항목마다 학습 목표도 넣어줘. 그리고 전문 용어 대신 쉬운 표현을 써줘. 예를 들면 "커밋"은 "변경 내용 저장"처럼. 4. 목차에 "협업 사례"도 추가해줘. 그리고 "PR" 설명은 "코드 검토 요청"으로 쉽게 설명해줘. 5. 톤은 더 친절하게, 그리고 확인 질문 없이 바로 결과를 보여줘.
